STEP 3: TESTING
================================================================================

Test Case 1: Send Email
-----------------------
1. Open quotation request modal
2. Select vendors and send email
3. Check database: ve_qr_version should match current_version

Test Case 2: Submit First Quotation
-----------------------
1. Submit vendor quotation
2. Check SP_VENDOR_QUOTATIONS: qr_version, is_current = 1
3. Check SP_VENDOR_QUOTATIONS_HISTORY: version_number = 1

Test Case 3: Update Quotation (Negotiation)
-----------------------
1. Update same quotation with new price
2. Check old quotation: is_current = 0
3. Check new quotation: is_current = 1
4. Check history: new version created

Test Case 4: Request Revised
-----------------------
1. Revise request quantity (creates new version)
2. Send email again
3. Check email log: ve_qr_version should be new version
4. Submit quotation
5. Check quotation: qr_version should match request version
